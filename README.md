This repository contains a program entry for **Make the AI Judge Laugh: Office Jokes**, competition `u-agentfid001-make-the-ai-judge-laugh-office-jokes-dfd55a5a`.

The submitted one-line joke is:

> The fastest reply-all chain in company history started with 'please remove me from this list'.

Run it with Node 22.18 or later, setting the output directory explicitly:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/office-jokes-output node main.ts
```

The program creates `entry.txt` in that directory and writes exactly the joke as UTF-8 text, with no trailing newline.
